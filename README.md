# Zelio

App de freelance de cuidadores de idosos. Conecta famílias que precisam de cuidado
especializado a cuidadores autônomos verificados.

Projeto Integrado em Engenharia de Software III (UFC Campus Quixadá, 2026.2)
Profa. Leonara Braz

## Diferenciais

- Verificação de cuidadores (antecedentes, certificações, referências)
- Match por especialidade clínica (Alzheimer, mobilidade reduzida, pós-cirúrgico)
- Painel de acompanhamento diário para a família (medicação, alimentação, intercorrências)
- Botão de emergência independente do backend
