# Registros de validação com stakeholder

Esta pasta guarda uma ficha por conversa realizada com alguém de fora do
projeto. É o item que a disciplina pede em toda sprint review.

## O que é evidência e o que não é

Uma ficha aqui registra o que uma pessoa real disse. Ela não registra o que eu
acho que a pessoa quis dizer, nem o que eu esperava ouvir.

Por isso cada ficha separa três campos que costumam ser confundidos:

- **Citação literal** — a frase como ela saiu, entre aspas. É o que sustenta
  qualquer conclusão depois.
- **Observação** — o que eu vi acontecer, incluindo reação não verbal.
- **Interpretação** — o que eu concluí. Fica separada de propósito, porque é a
  parte que pode estar errada.

## Grau de confiabilidade

Nem toda conversa vale o mesmo. Cada ficha declara o seu grau:

| Grau | O que significa |
|---|---|
| **Entrevista** | Conduzida com o roteiro, com consentimento registrado e notas feitas em até 24h |
| **Conversa informal** | Sem roteiro, anotada de memória depois. Serve como indício e para gerar hipótese, não como evidência de decisão |

Declarar o grau é o que separa coleta de dados de recordação conveniente.

## Convenção de nome

`ENT-NN-perfil-grau.md` — por exemplo, `ENT-02-familia-entrevista.md`.

Nenhuma ficha traz nome, endereço ou qualquer dado que identifique o
participante ou o idoso, conforme o termo de consentimento do roteiro.
