# Protótipo

A versão válida do protótipo é a do Figma, com as oito telas e a navegação ligada:
**[Zelio v1](https://www.figma.com/proto/0G8ldhOI6LclbkswGdjXa2/Zelio-v1?node-id=3-1102)**

O arquivo [`index.html`](index.html) desta pasta é a primeira rodada, feita antes da
redução de escopo. Ele tem seis telas, três das quais deixaram de existir no produto:
acompanhamento do serviço em andamento, registro diário e botão de socorro. As telas
de busca, perfil e solicitação de plantão continuam válidas e foram levadas para a
versão do Figma.

Está mantido aqui porque é registro de uma decisão de projeto: o escopo foi cortado
depois que ficou claro que o aplicativo intermedia a contratação, e não acompanha a
execução do cuidado.
